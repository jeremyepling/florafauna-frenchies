# FloraFauna Frenchies

This checkout builds NeoForge targets `:26.1-neoforge` and `:26.3-neoforge` with Java 25 and its checked-in Gradle wrapper. Check `versions/<target>-neoforge/gradle.properties` for the matching Minecraft and NeoForge versions. Shared sources and resources live under `src/main`; target-specific sources and resources live under `versions/<target>-neoforge/target`. Preserve existing entity, item, attachment, courier-save and resource identifiers when changing persistence. The standalone mod owns its tests under `florafauna_frenchies`.

During iteration, run the smallest check that exercises the change. Use `./gradlew :26.1-neoforge:test` or `:26.3-neoforge:test` for value and timing rules. For world behavior, run a filtered headless case, for example `./gradlew '-PgameTestFilter=florafauna_frenchies:frenchie_bedtime' :26.1-neoforge:runGameTestServer`. Run both targets' `build` and `runGameTestServer` tasks on an integrated revision for a substantial final pass or release. Inspect the selected test names, counts and failures. CI runs both targets: draft PRs get `check`; ready PRs and pushes to main get builds and the headless suite.

Independent headless and scripted-client checks can run concurrently when their build outputs, game directories and ports are separate. Each target writes under `versions/<target>-neoforge/build`, `run` and `.tmp`. Use the workspace `Invoke-MinecraftCheck.ps1` launcher and include every checkout a run can write. Reserve the desktop lock for steps using Windows input, focus or desktop capture.

For input, HUD, dialog, rendering or save/rejoin behavior, run the matching real-client scenario with `scripts/test_dev_world.ps1 -Target 26.1` or `-Target 26.3`. Use `scripts/test_delivery_multiplayer.ps1 -Target 26.1` for courier handoffs and `scripts/test_playful_interactions.ps1 -Target 26.1` for playful poses; choose 26.3 with either script for that version. The scripts default to 26.1, keep disposable game directories, and use separate ports for multiplayer runs. The singleplayer script requires a closed source world. Report which scenario, target and revision were verified.
